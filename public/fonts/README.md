Drop licensed font files here so `@font-face` in `styles/font.css` can load them.

Expected filenames:

- `P22Mackinac-Regular.woff2` (also `.woff` / `.ttf` optional)
- `CircularXX-Book.woff2` (also `.woff` / `.ttf` optional)
- `CircularXXMono-Regular.woff2` (also `.woff` / `.ttf` optional)

Until files are present, the UI falls back to Georgia / Helvetica / system mono.
